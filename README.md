# 🚨 Rapid Relief – Disaster Coordination System

## 📘 Overview

**Rapid Relief** is a full-stack web application designed to improve disaster response coordination during emergencies such as floods, cyclones, earthquakes, and fire incidents. Developed using the **MERN Stack**, the platform provides a centralized system that connects citizens, volunteers, and administrators to facilitate efficient disaster management and resource coordination.

The system enables citizens to report emergencies, request assistance, locate nearby shelters, and monitor the progress of their requests. Volunteers can register, receive rescue assignments, navigate to disaster locations, update rescue progress, and submit completion reports. Administrators oversee the entire disaster response process through an integrated dashboard that manages emergency requests, shelters, volunteers, resources, donations, and system analytics.

By integrating mapping services, weather information, and automated notifications, Rapid Relief aims to reduce emergency response time, improve communication among stakeholders, and support data-driven decision making during disaster situations.

---

# 🎯 Project Objectives

The primary objectives of Rapid Relief are to:

- Digitize and streamline disaster response coordination
- Reduce emergency response time through centralized management
- Improve communication between citizens, volunteers, and administrators
- Provide real-time monitoring of rescue operations
- Support efficient shelter and resource management
- Integrate external services to enhance situational awareness

# 👥 User Roles

## 👤 Citizen

Citizens can:

- Register and manage their profiles
- Submit emergency assistance requests
- Provide disaster location and incident details
- Track request status and rescue progress
- View nearby shelters
- Receive notifications and updates

---

## 🦺 Volunteer

Volunteers are responsible for assisting in rescue operations.

They can:

- Register as volunteers
- Receive administrator approval
- Accept rescue assignments
- Navigate to disaster locations
- Update rescue progress
- Submit completion reports
- Receive task notifications

---

## 🛠 Administrator

Administrators manage the overall disaster response workflow.

Responsibilities include:

- Managing users and volunteers
- Verifying volunteer registrations
- Assigning rescue tasks
- Managing shelters
- Monitoring shelter occupancy
- Managing emergency resources
- Tracking donations
- Monitoring emergency requests
- Viewing analytics and reports
- Sending notifications
